# Entity Analyzer — итоговый отчёт о работе

**Дата:** 25.08.2026
**Объём:** 13 кампаний — от удаления модуля атласа до полного покрытия QA и стратегии развития
**Итоговое состояние:** сборка 0 ошибок / 0 предупреждений · тесты **257/257** · SMOKE V10 **PASSED** · лог приложения без новых ошибок · `publish/` и `publish-cli/` актуальны

## 1. Резюме

За кампанию проект Entity Analyzer прошёл путь от тёмного WPF-GUI с падающей страницей «История» и мёртвым 3D-модулем до строгого академического инструмента с дизайн-системой «Камень, Графит и Лёд», декларативными семантическими паттернами v2, чтением 19 форматов файлов, гибким поиском совместных упоминаний и полностью закрытыми реестрами дефектов четырёх QA-отчётов (10 + 9 + 19 + 4 позиций), двух UX-отчётов (15 + 19 рекомендаций). Ни один ранее закрытый дефект не регрессировал. Сформулирована инновационная дорожная карта из 28 идей с ключевой рекомендацией.

**Эволюция тестового покрытия:** 201 → 214 → 216 → 223 → 232 → 238 → 250 → 254 → **257** тестов (+56 за кампанию, все зелёные, три подряд стабильных прогона на финальном коде).

## 4. Новая функциональность

### 4.1 Семантические паттерны (ядро `Core/Semantics/`)
- Декларативный JSON без изменения кода ядра; встроенные + пользовательские (`%APPDATA%\EntityAnalyzer\semantic_patterns.json`, перекрытие по id).
- Виды токенов: `literal`, `lexicon` (7 встроенных словарей), `proper`, `capitalized`, `regex`, `anyword`; квантификаторы `min`/`max`; операторы `any_of`, стражи `not`, `required:false`, окна `window`/`total_window`.
- Матчер: рекурсия с бэктрекингом по предложениям; первый токен ищется по всему предложению; между звеньями допускаются пропуски в пределах окна.
- Конфиг включён в сигнатуру инкрементального кэша; находки кэшируются вместе с файлом.
- Статистика срабатываний: CLI («Паттерн X: N совп. (M файлов)»), analysis_report.txt, entities_report.txt, журнал GUI.
- Обособленный скан `ScanPatternsOnly` + `--patterns-only` в CLI; результаты в собственных папках `by_pattern/<id>/matches.txt|csv|json`.
- Живое качество: 16 из 20 пользовательских примеров периодов («Год Красной Луны», «Час Воющей Собаки», «Эры Великой Расы»…) находятся встроенным паттерном «Названия периодов»; морфология головных слов (год/час/эра/век) докручена.

### 4.2 Гибкий поиск (co-occurrence)
Четыре режима по паре объектов: вместе в одном файле · рядом ≤N строк · в одном файле, но ≥N строк разнесены · первый без второго. Работает поверх готовой сессии (`Core/Analysis/CoOccurrenceQuery.cs`).

### 4.3 Детектор дубликатов текстов
SHA-256 группы копий; карта «хэш → первый путь» собирается всегда; плитка на дашборде, секция в отчёте, `duplicates.txt/csv`.

### 4.4 Форматы файлов (19 расширений)
Без внешних зависимостей: txt, md (UTF-8/CP1251/Latin1, UTF-16 по BOM), html/htm, rtf (парсер групп: `\uN`, `\'hh`, `\ucN`-фолбэки), fb2, epub, docx, odt, pdf (best-effort FlateDecode+Tj/TJ), doc (эвристика UTF-16LE/CP1251), mobi/prc/azw (PalmDB + LZ77 с кольцевым буфером), cbz (ComicInfo.xml). Честные предупреждения: cbr, djvu, lit, DRM/HUFF-CDIC. Список форматов настраивается чекбоксами на Обзоре.

### 4.5 Интерфейс
- Навигация: Обзор (вкладки «Обзор»/«Поиск и паттерны»), Результаты, Кодекс, Схемы, Отчёты (вкладки «Просмотр»/«Выгрузка»), История, Справка; рейка сворачивается.
- Онбординг: 3 шага + ссылка «Что такое кодекс?»; сводка «Поиск по кодексу: N карточек · M вариантов».
- Редактор семантических паттернов: форма + таблица токенов + JSON-предпросмотр + inline-валидация; широкое меню выбора с фильтром.
- Страница «Справка»: быстрый старт, кодекс, форматы, полный туториал по паттернам, гибкий поиск, масштаб, FAQ из 9 вопросов.
- Регулируемые границы: GridSplitter'ы между колонками Обзора/Результатов/Кодекса/Отчётов.
- Горячие клавиши: Ctrl+F (фокус в поиск страницы), F5 (обновить отчёты/историю), Ctrl+колесо (масштаб 0.8×–1.6×).
- Прозрачность: плитка «СКРЫТО ЛИМИТОМ», расшифровка плотности «/10k», статусы «Успешно/С ошибками (N)», колонка «ИЗ КЭША», сверка воронки, анонс записи отчётов, предупреждение о вложенной папке вывода.
- Безопасность просмотра: IE11-emulation для WebBrowser + кнопка «Открыть в браузере».
- Русские названия профилей («Быстрый (light)»…«Полный без ограничений (titanic)») при сохранении совместимости id в settings.json/CLI.

### 4.6 Обособление модуля «История»
`HistoryStore.DefaultPath/Default` — единая точка хранения; `HistoryViewModel.Record(session, dirs)` — модуль сам пишет журнал и обновляет таблицу; маппинг `SessionHistoryExtensions.ToRunRecord()` в слое Analysis без циклических зависимостей.

## 7. Инновационная дорожная карта (кратко)

28 идей по 8 областям (бэкенд, фронтенд, архитектура, DevOps, UX/UI, безопасность, ИИ, монетизация). Опорные вехи:

- **Первые 30 дней:** `verify.ps1` (вся верификация одной командой) · санитайзер+CSP для HTML-отчётов · performance-gate на baseline.json · песочница паттернов с live-превью · экспорт в Obsidian/Anki/Zotero.
- **Квартал 1:** «Кодекс-скаут» (discovery непокрытых имён) · дифф прогонов + diff-вид · компиляция паттернов в общий автомат Ахо–Корасика · self-verifying релиз · цепочка целостности журнала (prev_hash).
- **Квартал 2–3:** контракт `IAnalysisModule` · режим вычитки с подчёркиванием · бейджи уверенности · headless API · библиотека кодексов · шифрование кодексов · Pro-ключ (Ed25519).
- **Долгосрок:** инвертированный индекс корпуса · эмбеддинг-поиск (ONNX, офлайн) · классификатор омонимии · академические отчёты «под публикацию».

**Ключевая рекомендация:** первой внедрять «Кодекс-скаут» — единственная идея, атакующая корневое ограничение продукта («ищу только тех, кого уже знаю»), поверх существующей инфраструктуры, MVP за пару дней.

## 8. Известные ограничения и техдолг

1. **В репозитории нет git** — вся история изменений держится на файлах. Настоятельно рекомендуется инициализировать контроль версий.
2. Python-легаси v18 заморожен: правки вносились строго по QA-отчётам; дальнейшее развитие только в .NET-версии.
3. PDF-экстрактор best-effort (без layout-анализа); сканы без OCR-слоя не читаются; doc — эвристика; cbr/djvu/lit — только предупреждение.
4. Встроенный просмотрщик HTML — legacy WebBrowser (IE11-emulation); для сложных отчётов предусмотрена кнопка «Открыть в браузере».
5. В `settings.json` путь корпуса может указывать на устаревший временный каталог прошлой сессии — при первом запуске выбрать корпус заново.
6. Тесты, пишущие в глобальный Log, объединены в сериальную коллекцию `LogSequential`; пользовательские конфиги паттернов в тестах изолируются переменной `EA_SEMANTIC_USER_DIR`.
